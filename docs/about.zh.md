# 关于 Kerbalism

Kerbalism 最初由 **ShotgunNinja** 打造，现在由社区维护者（包括 R-T-B 等）接着看顾。模组仍然能好好玩，但**不是全职火力全开开发**。

本站是 Kerbalism 的 **MkDocs Material** 文档（中英文），由 GitHub Wiki 迁移而来。正式下载请以 [GitHub Releases](https://github.com/Kerbalism/Kerbalism/releases) / CKAN 为准。

- 许可证：[Unlicense](https://github.com/Kerbalism/Kerbalism/blob/master/LICENSE)（公有领域）
- 源码：https://github.com/Kerbalism/Kerbalism
- 贡献指南：https://github.com/Kerbalism/Kerbalism/blob/master/CONTRIBUTING.md
- Discord：https://discord.gg/3JAE2JE
- Issues：https://github.com/Kerbalism/Kerbalism/issues
