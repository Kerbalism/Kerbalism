# Play guide

Guides for playing with Kerbalism on **KSP 1.12.x**.

Suggested order:

1. [Tutorial: Going to the Mun](basic-tutorial.md)
2. [User interface (GUI)](gui.md)
3. [Life support](life-support.md)
4. [Tutorial: Doing science](science-tutorial.md)

For long-duration stations and colonies, see [Greenhouse balance](greenhouse-balance.md) (continuous production and mass break-even).

Communications default to CommNet (RemoteTech is optional and higher risk).
