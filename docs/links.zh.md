# 下载与链接

## 当前版本

**Kerbalism 3.40**，面向 **KSP 1.12.x**。

- [GitHub Releases](https://github.com/Kerbalism/Kerbalism/releases)（首选）
- [CKAN](https://forum.kerbalspaceprogram.com/index.php?/topic/197082-ckan)（省心处理依赖）
- 可选试验构建：[DevBuilds](https://github.com/Kerbalism/DevBuilds/releases)

源码在 [github.com/Kerbalism/Kerbalism](https://github.com/Kerbalism/Kerbalism)。源码 zip **不是**发行包——只装 `GameData/`，以及你选用的 [Extras](https://github.com/Kerbalism/Kerbalism/tree/master/Extras)。

## 安装

始终需要 **两个** 包：

1. **Kerbalism** — 核心插件
2. **恰好一个**配置包 — 官方 `KerbalismConfig`，或第三方包（ROKerbalism、SIMPLEX、SkyhawkKerbalism、LessRealThanReal(ism) 等）

除非配置包自己写明可以叠用，否则不要混装。
