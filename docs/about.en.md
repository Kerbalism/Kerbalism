# About Kerbalism

Kerbalism was originally created by **ShotgunNinja**. It is now maintained by community contributors (R-T-B and others). The mod is still playable, but it is **not under full-time active development**.

This site is the **MkDocs Material** documentation for Kerbalism (English / Chinese), migrated from the GitHub Wiki. Downloads remain on [GitHub Releases](https://github.com/Kerbalism/Kerbalism/releases) or CKAN.
