# Downloads and links

## Current release

**Kerbalism 3.40** for **KSP 1.12.x**.

- [GitHub Releases](https://github.com/Kerbalism/Kerbalism/releases) (preferred)
- [CKAN](https://forum.kerbalspaceprogram.com/index.php?/topic/197082-ckan) (recommended for dependency resolution)
- Optional experimental builds: [DevBuilds](https://github.com/Kerbalism/DevBuilds/releases)

Source: [github.com/Kerbalism/Kerbalism](https://github.com/Kerbalism/Kerbalism). A source zip is not a release package — only install the contents of `GameData/` (and any chosen [Extras](https://github.com/Kerbalism/Kerbalism/tree/master/Extras)).

## Installation

You always need **two** packages:

1. **Kerbalism** — core plugin
2. **Exactly one** configuration pack — official `KerbalismConfig`, or a third-party pack (ROKerbalism, SIMPLEX, SkyhawkKerbalism, LessRealThanReal(ism), …)

Do not combine config packs unless that pack explicitly says so.
